# AI 分析

在 ROS Watch 左侧打开「AI 分析」，点击「配置连接」。可以保存多个模型连接，并为新页面指定默认模型。切换模型时开始新对话。选择一个已保存的连接，再点击「测试已保存连接」，用模拟工具核对模型能否调用工具并根据回传结果回答。

## 模型连接

点击「添加连接」即可选择常用服务。预设自动填写连接名称、模型 ID 和 Base URL。已有同地址的连接时会打开该连接。填写自己的 API Key，保存后测试工具调用。Kimi 国内和国际平台各有预设。通义千问使用专属业务空间或其他区域时，Base URL 以提供方控制台为准。

添加或编辑时，填写 Base URL 和所需的 API Key 即可点击「刷新模型列表」，从服务返回的模型中选择。模型较少时会直接列出，较多时使用下拉菜单。此操作请求 Base URL 下的 `/models`，保存前即可使用。服务未实现该接口时可手动输入模型 ID。工具调用能力可通过「测试已保存连接」核对。

「OpenAI 官方」预填 OpenAI 官方地址。「OpenAI 兼容」用于 New API、自建中转和其他兼容网关，填写服务给出的 Base URL 和 API Key。Base URL 保留服务提供方的路径前缀，例如 `https://gateway.example.com/v1`。服务端在 Base URL 后请求 `/chat/completions`。

公网连接使用 HTTPS。内网 Ollama 等服务可以使用局域网 IP、`localhost` 或 `host.docker.internal` 的 HTTP 地址，端口从 ROS Watch 所在服务或容器的视角填写。无密钥的服务可以把 API Key 留空。密钥保存在 ROS Watch 的控制数据库，网页只显示是否已配置。修改 Base URL 后请为新地址填写相应凭据。

## 查询与证据

- 疑似扫描支持时间、国家代码、单个 IP 和 CIDR 网段，沿用当前扫描阈值、固定窗口和正常业务排除规则。
- 访问查询按来源统计目标端口、连接方向、访问对象和日志类型。登录查询可按国家或具体来源 IP 核对成功、失败和退出日志。
- 分析可查最近 168 小时内实际保留的记录。回答附带访问记录或系统日志的筛选链接。链接打开对应的最近时间范围，工具结果以本次回答的查询时间为准。
- 对话上下文暂存在服务端内存，同一登录会话可连续追问。对话闲置 45 分钟后过期，长对话仅保留最近有界的上下文。

「IP 情报」可启用 GreyNoise、AbuseIPDB 和 Spamhaus DROP / ASN-DROP。AbuseIPDB 需要 API Key。启用 Spamhaus 时使用官方名单，并用 RIPEstat 查待查 IP 的宣告 ASN。对话按需查询公网来源 IP，结果区分未启用、无记录、限额及服务不可用。

模型服务接收输入的问题、近期对话和结构化统计。日志原文由 ROS Watch 本地页面展示。第三方情报服务收到的是待查公网 IP。分析工具使用只读日志查询，可在证据链接里复核日志记录和采样边界。

## 自定义 IP 情报

展开「配置连接 → IP 情报 → 自定义 IP 情报」。填写返回 JSON 的查询地址，比如 `https://intel.example.com/lookup?ip={ip}` 或 `https://intel.example.com/ip/{ip}`。ROS Watch 会替换 `{ip}` 并发出 GET 请求。公网接口使用 HTTPS，局域网 IP 可使用 HTTP。认证可选 Bearer、X-API-Key、Key 请求头或无认证。密钥填在 API Key 字段中。

将返回的 JSON 字段映射到报告所需的含义，例如把 `data.score` 填在评分字段。可映射分类文本、布尔型名单命中、0–100 评分、整数举报数和 ISO 格式的最后出现时间。填好至少一个字段并启用后，保存接口，再输入一个公网 IP 点击「测试已保存接口」。这项测试直接查询情报接口。对话中的「查黑记录」也可使用同一接口，模型收到的是映射结果、状态和查询时间。

## 示例

1. 分析最近 7 天的保加利亚扫描，列出来源和网段。
2. 这些来源有什么公开信誉记录？
3. 核对它们有没有 RouterOS 登录成功记录。
4. 给我 ROS 的封禁指令。页面会使用最近一次扫描查询里的 IPv4 来源组合现有 `blocked-sources` 指令，也可在问题中指定 IPv4 地址。核对后可一键复制到 RouterOS 终端。
