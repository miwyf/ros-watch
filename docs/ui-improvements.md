# 界面整改记录

以下项目已在 0.7.2 完成，本机隔离 Docker 及浏览器验证通过后统一发布。

## 顶部导航文字

- 移除固定的“工作空间 / 网络安全 /”前缀。它们没有对应模块或跳转功能。
- 顶部保留当前页面名称；账号、连接状态、退出操作继续保留。

## 系统设置分区

问题：日志规则、账号安全和告警通知目前同时显示，页面过长；RouterOS 接入属于配置流程，适合一并归入系统设置。

已采用：保留侧栏“系统设置”入口，内部划分四个标签页，每次只显示一个分区。

| 标签页 | 内容 |
| --- | --- |
| 日志与观察规则 | 日志来源、WAN 映射、保留与磁盘设置、接收限速、队列、扫描阈值及存储状态 |
| 账号安全 | 用户名、当前密码、新密码及确认密码 |
| 告警通知 | 平台、Webhook、签名密钥、告警类型、可信管理来源、发送状态及测试发送 |
| RouterOS 接入 | 接入脚本生成、复制、检查和撤销指令 |

- 各分区独立操作，保存或测试一个分区不提交其他分区；RouterOS 接入继续生成指令供用户手动执行。
- 切换标签时保留尚未保存的输入。
- 告警通知继续归属系统设置，不增加独立的侧栏一级入口。
- 移除侧栏独立的“RouterOS 接入”入口，将其内容放入对应设置标签。
- 保留现有 `/#routeros` 链接的兼容跳转，进入系统设置的 RouterOS 接入标签。
- 手机端也只显示当前分区，标签与表单不得产生横向溢出。

## 验证与发布方式

- 已验证四标签独立显示、未保存输入保留、日志与通知分别保存、RouterOS 脚本生成与标签间保留、旧链接兼容、刷新定位、键盘切换及手机布局。
- 较长的存储和通知统计默认折叠，状态摘要直接显示；磁盘异常提示保持可见。
- 改动先在本地 Docker 验证，不推送中间试验提交。
- 纯 Markdown 文档不触发镜像构建。版本标签优先引用同一提交已发布的镜像，避免重复构建。
